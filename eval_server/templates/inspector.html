ℹ️ How are these metrics calculated?
G_ground (Grounding Score): Rule-based, no-LLM score for whether the agent targeted a real element: 1.0 when an element index is present, 0.7 when only matching by text, 0.0 when no target (— for done/scroll). This is what feeds C_t. (Currently checks that an index is present, not yet that it resolves in the page snapshot.)
LLM grounded: The model's own self-reported grounding (0–1), shown alongside for comparison. Not used in C_t.
L_t (Old Loop Penalty): Computed post-hoc from the trace — the fraction of all previous actions with the same element/action text (element text, falling back to the instruction), regardless of action type.
L_t_u (Updated Loop Penalty): Same denominator as L_t, but a match requires the same normalized action type and the same element/action text. For example, click Search and type Search are no longer treated as the same loop.
Goal Relevance: How relevant the step is to the goal — cosine similarity between an embedding of the step instruction and an embedding of the predicted final goal state (text-embedding-ada-002). This measures relevance, not real progress. Shown for insight; not factored into C_t. Blank when no embedding is available.
Progress: The agent's own LLM-self-reported progress for the step (range −1 to 1). A separate signal from Goal Relevance. Shown for insight; not factored into C_t.
C_t (Step Confidence): clip(G_ground × (1 − 0.5 × L_t_u), 0, 1). Goal Relevance and Progress are informational and not part of this formula.
