📊 Step Uncertainty Breakdown
Step Uncertainty (U_t = clip(1 − internal grounding × (1 - 0.5 × L_t_u), 0, 1); higher = more uncertain)
Scroll steps (scroll_down, scroll_up) are excluded — they return None and are omitted from aggregations.
ℹ️ How are these metrics calculated?
Grounding Similarity: Raw cosine similarity between the step instruction and target element text. Values ≥ 0.80 are shown green; lower available values are shown yellow.
LLM grounded: The model's own self-reported grounding (0–1), shown alongside for comparison. Not used in C_t.
L_t (Old Loop Penalty): Computed post-hoc from the trace — the fraction of all previous actions with the same element/action text (element text, falling back to the instruction), regardless of action type.
L_t_u (Updated Loop Penalty): Same denominator as L_t, but a match requires the same normalized action type and the same element/action text. For example, click Search and type Search are no longer treated as the same loop.
LLM Progress: The agent's own LLM-self-reported progress for the step — three-point: 1.0 clear progress, 0.5 no net / exploratory movement, 0.0 regression. Shown for insight; not factored into C_t.
Subgoal Progress: Deterministic. The LLM authors an ordered subgoal rubric once per task; the system then verifies each subgoal from page state (URL/DOM) every step. 1.0 = verified count increased, 0.5 = unchanged, 0.0 = decreased or returned to a previously-seen state without a new subgoal.
U_t (Step Uncertainty): clip(1 − internal grounding × (1 − 0.5 × L_t_u), 0, 1); higher = more uncertain (low grounding / high loop). Progress signals are informational and not part of this formula.
