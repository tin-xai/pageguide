# PageGuide

PageGuide is a browser extension that helps users find information, navigate websites, and verify answers directly on the page.

## Features

- **Find:** Ask a question about the current webpage. PageGuide answers it and highlights the supporting text or visual evidence.
- **Guide:** Receive step-by-step instructions for completing a task. PageGuide highlights the relevant button or field and waits for confirmation before continuing.
- **Image Asking:** Upload or paste an image to locate matching visual content on the current page.
- **PDF Asking:** Upload a PDF, ask questions about it, and use citations to jump directly to supporting passages.

## Installation

PageGuide supports Chrome and Edge.

1. Download and extract the PageGuide ZIP archive.
2. Open `chrome://extensions/` in Chrome or `edge://extensions/` in Edge.
3. Enable **Developer mode**.
4. Select **Load unpacked**.
5. Choose the extracted `pageguide` folder.
6. Pin the PageGuide icon to the browser toolbar.
7. Select the icon to open the side panel.

## First-Time Setup

1. Open PageGuide and select **Settings**.
2. Choose an LLM provider:
   - Google Gemini
   - OpenAI
   - OpenRouter
3. Enter your API key.
4. Select **Test & Save Connection**.
5. Optionally enable screenshot-based visual analysis or numbered webpage-element labels.

The API key is stored in the local browser profile.
